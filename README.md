## 🎵 Music Store Data Analysis

This project focuses on analyzing a music store's sales and customer data using **SQL** to uncover meaningful business insights. The analysis explores customer purchasing behavior, music preferences, sales performance, and revenue trends.

### 🔍 Key Analysis

* Identified the **top-selling artists, albums, and tracks**
* Analyzed **customer purchasing patterns**
* Found the **highest-revenue customers and countries**
* Analyzed sales by **genre and artist**
* Identified **popular music categories**
* Calculated total revenue, average order value, and sales performance
* Used SQL **JOINs, GROUP BY, aggregate functions, subqueries, CTEs, and window functions**

### 🛠️ Tools & Technologies

* **PostgreSQL**
* **SQL**
* **pgAdmin**
* GitHub

### 🎯 Objective

The main objective is to use SQL-driven analysis to understand customer behavior and sales performance and provide data-driven insights that can support business decision-making.
